# DeclarativeUIKit

DeclarativeUIKit is a Swift library that brings a SwiftUI-like declarative syntax to UIKit.

## Overview

Traditional UIKit development can be verbose and hard to read. DeclarativeUIKit simplifies this by providing a fluent interface and result builders, allowing you to describe your UI hierarchy in a clean and readable way.

### Key Features

- **Fluent Interface**: Chain configuration methods directly on your views.
- **Result Builders**: Build view hierarchies with `vStack`, `hStack`, and `zStack`.
- **Safe Layout**: Easy Auto Layout constraints with built-in safe area handling.
